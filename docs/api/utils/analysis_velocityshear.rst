analysis_velocityshear
======================

Overview
--------

``analysis_velocityshear`` computes the velocity shear tensor :math:`S_{ij}` for all SPH particles using neighbour lists, then finds its eigenvalues and eigenvectors via the Jacobi iteration method. This provides a local measure of the rate of deformation of the fluid, with applications in turbulence characterisation and vortex identification.

The symmetric shear tensor :math:`S_{ij} = \frac{1}{2}(\partial_i v_j + \partial_j v_i)` is estimated from the SPH velocity gradient, using the neighbour list generated by ``generate_neighbour_lists``. The three eigenvalues :math:`\lambda_1 \geq \lambda_2 \geq \lambda_3` and corresponding eigenvectors are computed for each particle and written to output files.

Regions with :math:`\lambda_1 \lambda_2 > 0` and :math:`\lambda_3 < 0` correspond to vortex cores (the :math:`\lambda_2` criterion), providing a means to identify vortical structures in the flow.

Physical & Mathematical Description
------------------------------------

The velocity shear tensor is :math:`S_{ij} = \frac{1}{2}(\partial_i v_j + \partial_j v_i)`, estimated via the SPH gradient :math:`\partial_i v_j \approx \sum_k m_k (v_{j,k} - v_{j,i}) \partial_i W_{ik} / \rho_i`. The eigenvalues are the solutions of :math:`\det(S_{ij} - \lambda \delta_{ij}) = 0`, found via Jacobi iteration with up to ``it_max = 10`` iterations.
