moddump_binarystar
==================

Overview
--------

``moddump_binarystar`` converts a single relaxed star dump into a binary star system by placing a copy of the star at a specified separation, suitable for neutron star or white dwarf merger simulations. Written by Terrence Tricco, it uses the gravitational wave inspiral external force to allow the stars to spiral in under GW radiation reaction.

The user specifies the binary mass ratio, synchronisation parameter (for spin-orbit coupling), and the initial separation. The second star is generated by copying the particle distribution of the first star and placing it at the specified separation, with velocities set for a circular Keplerian orbit. Optional gravitational wave inspiral parameters (``iext_gwinspiral``) are set for the merger simulation.

This moddump is specifically designed for compact binary merger simulations where the two stars have identical or similar structures, enabling a single relaxed stellar model to be used as both binary components.

Physical & Mathematical Description
------------------------------------

The binary separation and velocities are computed from the two-body problem: for a circular orbit with semi-major axis :math:`a` and total mass :math:`M = m_1 + m_2`, each star orbits the centre of mass at :math:`r_k = m_{\bar{k}} a / M` with angular velocity :math:`\Omega = \sqrt{G M / a^3}`. The inspiral rate from gravitational wave emission is :math:`\dot{a} = -64 G^3 m_1 m_2 M / (5 c^5 a^3)`.
