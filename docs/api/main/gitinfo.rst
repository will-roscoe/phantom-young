gitinfo
=======

Overview
--------

The ``gitinfo`` module writes version control metadata to the Phantom log
file at startup. The public subroutine ``get_and_print_gitinfo`` reads the
``phantom-version.h`` include file generated by the build system script
``scripts/phantom_version_gen.sh``, which records the current git commit
SHA, the branch name, and a list of recently modified source files. This
information is printed in the run header so that every log file contains an
exact record of the code version that produced the simulation.

The public module variable ``gitsha`` stores the 7-character abbreviated
commit hash as a string, which is also embedded in dump file headers for
provenance tracking. If the version file is not present (e.g., in a clean
source tree without a git history), the subroutine silently skips the output.

Physical & Mathematical Description
------------------------------------

This module performs no physics or numerical calculations. It is a
metadata and logging utility. The version information it records is
essential for reproducibility: by checking the git SHA recorded in the log
file, a user can always determine exactly which version of the code produced
a given set of simulation outputs and reproduce the run from scratch.
