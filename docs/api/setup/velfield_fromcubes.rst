velfield_fromcubes
==================

Overview
--------

The ``velfield_fromcubes`` module reads pre-computed turbulent velocity
fields stored in cube-format binary files and interpolates them onto
Phantom particle positions.  These cube files are generated by external
codes (typically a spectral fluid code) that solve for driven or decaying
turbulence in a periodic box; the resulting three-component velocity field
is stored as a regular Cartesian grid with the same spacing in all three
directions.  The module handles multiple cube files (e.g.\ one per velocity
component) and performs trilinear interpolation to transfer the grid data
to the SPH particle positions.

This approach is used to set up turbulent molecular cloud collapse and ISM
simulations where the initial velocity spectrum must closely follow a
prescribed power law (e.g.\ Kolmogorov :math:`P(k) \propto k^{-11/3}` or
Burgers :math:`P(k) \propto k^{-2}`) that is difficult to generate
accurately from random Fourier modes at finite particle number.

Physical & Mathematical Description
------------------------------------

The cube file contains the velocity field :math:`v_i(\mathbf{r})` for
:math:`i \in \{x, y, z\}` on a uniform grid with :math:`N^3` cells of
size :math:`\Delta x = L/N`, where :math:`L` is the box length.  The
velocity at an arbitrary position :math:`\mathbf{r}_a` (particle
position) is obtained by trilinear interpolation,

.. math::

   v_i(\mathbf{r}_a) = \sum_{j,k,l \in \{0,1\}}
   w_j\,w_k\,w_l\; v_i(x_{n+j},\, y_{m+k},\, z_{p+l}),

where :math:`(n, m, p)` is the grid cell containing :math:`\mathbf{r}_a`
and the weights :math:`w_j = |x_a - x_{n+j}|/\Delta x` are the bilinear
weights in each direction.  Periodic wrapping is applied so that particles
near the box boundary correctly see the opposite face of the cube.  After
interpolation the velocity field is normalised so that the rms velocity
dispersion matches a target Mach number :math:`\mathcal{M}` specified at
setup time.
