set_disc
========

Overview
--------

The ``set_disc`` module provides the core utility routines for initialising
accretion and protoplanetary disc particle distributions in Phantom.  It
constructs the SPH particle layout for a disc in cylindrical coordinates,
populating the position, velocity, and thermodynamic arrays so that the disc
is in centrifugal balance from the outset.  The disc can be either a simple
gas disc or a gas–dust mixture, and arbitrary inclinations and warps can be
applied after the particles are placed.

The module exposes the central ``set_disc`` routine together with helpers for
computing the disc mass, scaling the surface density, and applying warps or
inclined configurations.  Runtime parameters such as the inner and outer disc
radii (``R_in``, ``R_out``), the surface density power-law index, the
characteristic taper radius ``R_c``, the Toomre Q parameter floor, and the
temperature at a reference radius are all configurable through the ``.in``
parameter file.  Optional support for a Shakura–Sunyaev :math:`\alpha`
viscosity prescription is included.

The Toomre stability criterion is used to convert the desired minimum-Q value
into a sound-speed profile, ensuring that the disc is marginally stable where
required.  Disc structure generated by this module is consistent with the
warped-disc analytic framework described by :cite:`lodatoprice10` and with the
gravitational fragmentation test suite discussed in Meru & Bate (2012,
MNRAS 427, 2022).

Physical & Mathematical Description
------------------------------------

The surface density profile follows a tapered power law,

.. math::

   \Sigma(R) = \Sigma_0 \left(\frac{R}{R_0}\right)^{-p}
               \exp\!\left[-\left(\frac{R}{R_c}\right)^{2-p}\right],

where :math:`p` is the ``p_index`` runtime parameter and :math:`R_c` is the
exponential taper radius.  Setting :math:`R_c \to \infty` recovers a pure
power-law profile.  The normalisation :math:`\Sigma_0` is determined by
requiring that the integral over the disc equals the requested disc mass
:math:`M_\mathrm{disc}`.

The sound speed profile is set as a power law in cylindrical radius,

.. math::

   c_s(R) = c_{s,0}\left(\frac{R}{R_0}\right)^{-q/2},

where :math:`q` is the ``q_index`` parameter.  This produces the temperature
profile :math:`T \propto R^{-q}`.  The Toomre stability parameter,

.. math::

   Q = \frac{c_s \,\Omega}{\pi G \Sigma},

is evaluated at each radius; if a minimum :math:`Q_\mathrm{min}` is
specified the sound speed is raised locally to enforce stability.  Particle
velocities are set to the local Keplerian value
:math:`v_\phi = \sqrt{GM_\star / R}` corrected for pressure support.
